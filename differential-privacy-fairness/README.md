# MAT180 - Fairness & Privacy in ML

This folder explores both differential privacy and fairness using the COMPAS recidivism scores.

## Contents
- `code_1.py` – Differentially private K-Means clustering. The script saves plots to `plots/` and falls back to a synthetic data set if `kmeansexample.asc` is missing.
- `code_2.py` – Fairness metrics computed from `compas-scores.csv`.
- `report.pdf` – Final writeup from the course project.

## Usage
1. Install the required Python packages (`numpy`, `pandas`, `matplotlib`, `scikit-learn`).
2. Execute the analysis:
   ```bash
   python code_1.py
   python code_2.py
   ```
   Plots generated by `code_1.py` are saved in the `plots` directory.

## Results
`code_1.py` illustrates how adding Laplace or Gaussian noise impacts the K-Means objective and clustering accuracy. `code_2.py` prints confusion matrices for African-American and Caucasian groups and shows recidivism probabilities for each COMPAS score, demonstrating differences between groups.
