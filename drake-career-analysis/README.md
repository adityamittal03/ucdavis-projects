# Drake Streams Analysis

This repository contains the final course project for **STA 141B — Data & Web Technologies for Data Analysis**. We analyze trends in Drake's music career using web-scraped data and API queries. See `drake_career_analysis_report.html` or `drake_career_analysis_report.pdf` for results and visualizations. `drake_career_analysis.ipynb` contains the notebook recreated from the HTML report.
