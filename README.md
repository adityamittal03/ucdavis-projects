# UC Davis Statistics Projects

This repository collects final projects from several UC Davis courses in statistics and data science. Each directory contains the code and final report for a particular course project.

## Projects

- **ECS171 - Machine Learning** – Diamond price prediction using regression, ensemble models, and neural networks.
- **ECS189G - Fairness in ML** – Fairness analysis on the German credit dataset.
- **MAT167 - Applied Linear Algebra** – Handwritten digit recognition with logistic regression, SVM, and SVD.
- **MAT180 - Fairness & Privacy in ML** – Exploring bias in the COMPAS recidivism scores.
- **STA106 - Analysis of Variance** – Course project reports on ANOVA techniques.
- **STA108 - Linear Regression** – Modeling `Carseats` sales with linear regression.
- **STA135 - Multivariate Data Analysis** – Multivariate tests on milk transportation cost data.
- **STA141A - Data Science I** – Investigating factors that influence song popularity on Spotify.
- **STA141B - Data Science II** – Web-scraped analysis of Drake's music and popularity.
- **STA141C - Data Science III** – Predicting flight delays using classification models.
