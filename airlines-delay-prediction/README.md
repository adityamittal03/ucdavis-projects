# Airlines Delay Prediction

This repository contains the final project for **STA 141C Big Data & High Performance Statistical Computing**. Our goal is to predict flight delays using several classification models trained on `airlines_delay.csv`.

The original analysis was contained in a single notebook. For clarity, the work has now been split into multiple notebooks:

1. `01_data_and_eda.ipynb` – load the data, create simulated datasets and perform exploratory analysis.
2. `02_logistic_regression.ipynb` – logistic regression implementations (gradient ascent and descent) and timing results.
3. `03_naive_bayes.ipynb` – Naive Bayes classifier experiments.
4. `04_knn.ipynb` – K‑NN classifier experiments.
5. `05_mlp.ipynb` – simple multi‑layer perceptron model.

See `airlines_delay_report.pdf` for a summary of the findings.
